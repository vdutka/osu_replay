This opens the JavaScript source. Allow Userscripts on raw.githubusercontent.com for installation, then open Safari’s page menu → Extensions → Userscripts and confirm Install. Downloading a file alone does not install it.

The JavaScript loader is only about 18 KB; it loads the player separately. Its size is expected. It must be named osu-replays.user.js, not .json.

One phone. Four steps.

  1. Get UserscriptsInstall the free Userscripts app and open it once. Keep its default scripts folder.
  2. Enable it in SafariIn Settings → Apps → Safari → Extensions, enable Userscripts and Allow Website Access for osu.ppy.sh. For browser installation also allow raw.githubusercontent.com. In the Userscripts popup, keep both global injection and this script enabled. Names may differ on older iOS versions.
  3. Install or replace the scriptUse the source link above and confirm Install in Userscripts. If Safari downloads it, use the ZIP link instead: open Files → Downloads, tap the ZIP to extract it, then move osu-replays.user.js into the folder shown by the Userscripts app. Open the Safari Userscripts menu once. Replace the older copy; keep one enabled script.
  4. Verify it is runningOpen the installation check on osu! and reload once. You should see “Replays 1.0.0.4 is running.” Then open any profile’s Records section and tap Watch replay. Let the files load, then tap Play to enable audio.

If loading stops

The diagnostic line identifies the stage that failed. Report that message, your iOS and Userscripts versions, and the public score link. Never share cookies, credentials, signed download links or private replay files.

Beatmap or music did not download

Confirm you are signed in and that osu! permits this download. Safari session handling and mirror redirects are still being tested. A replay without music does not pass this prototype’s acceptance check.

The script is listed, but nothing happens on osu!

Being listed under All scripts only means the file was found. On the installation-check page, open Safari → Userscripts, allow access to osu.ppy.sh, and confirm the global injection switch and this individual script are on. Reload the page. If the running message is absent, the script has not executed; replay downloads are not involved yet. Update older versions using the links above. This version also starts on the osu! home page so opening a profile through site navigation works.

Update or remove the script

For updates, revisit this page and install the latest script, replacing the previous copy rather than keeping two enabled. Remove it from the Userscripts folder or disable it through Userscripts. Player files are versioned so existing installs keep their matching engine.

What leaves my phone?

The player downloads its static code and artwork from this hosting origin. Score and replay data are processed in your browser; there is no processing backend or telemetry. The hosting provider and osu! receive ordinary web requests. Playback data is transferred locally between the osu! page and player frame.
